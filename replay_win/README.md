# 行业轮动 Replay — Windows 版使用说明

## 启动
1. 整个文件夹拷到笔记本任意位置(如 D:\replay\)，**不要放桌面/C盘系统目录**
2. 双击 **启动.bat**（若 Windows SmartScreen 拦截：点"更多信息"→"仍要运行"）
3. 浏览器自动打开页面，开始使用
4. 用完直接关掉黑色命令行窗口即可

## 说明
- 数据快照日期：见页面底部/数据末根K线（2026-10-12，前复权）
- 仅监听 127.0.0.1，局域网其他设备无法访问
- 交易记录保存在浏览器 localStorage：换浏览器/清缓存会丢，同一浏览器永久保留
- 想更新数据：回 WSL 主机跑日更后重新打包（或保持现状当静态快照用）

## 文件清单
- 启动.bat / serve.ps1    启动器（PowerShell 起本地 HTTP 服务）
- index.html              页面（静态版）
- universe/indmap/cross/tier.json   股票池/行业映射/热力图数据
- ind/                    90 个行业指数K线
- stock/                  5,809 只个股前复权K线(gz)
